# Conversor de Divisas (Currency Converter)


## Descripción
Elegimos 'Currency Converter' (Tier 2 de App Ideas) porque resuelve la necesidad de calcular conversiones de divisas en tiempo real para usuarios que realizan compras internacionales o viajes. Su alcance permite aplicar conceptos de peticiones a APIs externas, manejo de respuestas JSON y gestión de tasas de cambio dinámicas en un proyecto alcanzable para el equipo.

## User Stories
- Como usuario, quiero ver una lista de monedas de origen y destino disponibles para seleccionar cuáles quiero convertir.
- Como usuario, quiero ingresar un monto numérico para calcular su equivalencia en la moneda seleccionada.
- Como usuario, quiero ver la tasa de cambio actual utilizada para realizar el cálculo de conversión.
- Como usuario, quiero presionar un botón para intercambiar la moneda de origen con la de destino de forma rápida.
- Como usuario, quiero ver un mensaje claro de error si la API de divisas no está disponible o falla la conexión.

## Metodología
Ágil (Kanban) — Se seleccionó una metodología ágil ligera organizada en un tablero Kanban con tres columnas (To do, In progress, Done). Este enfoque permite entregas parciales rápidas, visibilidad constante del avance de cada integrante y flexibilidad para ajustar tareas durante la integración de la API.
