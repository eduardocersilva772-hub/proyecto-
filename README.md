# Sistema Habit Tracker

## Descripción
Elegimos 'Habit Tracker' (Tier 1 de App Ideas) porque resuelve la necesidad de dar seguimiento diario a hábitos personales sin depender de aplicaciones comerciales con suscripción. Su alcance (registro de usuario, alta de hábitos y marcado diario) es alcanzable por un equipo principiante en el tiempo disponible de la práctica.

## User Stories
- Como usuario, quiero registrarme con correo y contraseña para crear una cuenta personal.
- Como usuario, quiero crear un nuevo hábito con un nombre y frecuencia para darle seguimiento.
- Como usuario, quiero marcar un hábito como completado en el día actual para registrar mi avance.
- Como usuario, quiero ver una lista de mis hábitos del día para saber cuáles tengo pendientes.
- Como usuario, quiero eliminar un hábito que ya no necesite para mantener mi lista organizada.

## Metodología
Ágil (Kanban) — Se seleccionó una metodología ágil ligera organizada en un tablero Kanban con tres columnas (To do, In progress, Done). Este enfoque permite entregas parciales rápidas, visibilidad constante del avance de cada integrante y flexibilidad para ajustar tareas durante el desarrollo del mini-proyecto.
